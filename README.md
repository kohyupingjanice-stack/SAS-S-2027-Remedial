# SAS(S) Remedial 2027

This repository contains a lightweight static web app that visualises the remedial student roster from the provided CSV data.

## Included files

- `index.html` – dashboard layout
- `styles.css` – styling for the tracker
- `script.js` – CSV parsing and search/filter logic
- `data/Testing_Remedial.csv` – source data extracted from the provided remedial sheet

## How to use

1. Open `index.html` in a browser, or serve the folder with any static web server.
2. Use the search box to filter by register number, name, class, or subject.
3. Review the summary cards and the detailed student table.

## Notes

The data file uses the information supplied in the attached remedial sheet and is intended to be easy to update if more students or subject rows are added.
